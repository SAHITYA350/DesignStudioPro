# Design Studio Pro 🎨

A modern feature-rich design tool built with React, Konva, and DaisyUI. Create stunning designs with a Figma/Canva-like experience.

## Features ✨

- **Drawing Tools**: Rectangle, Circle, Arrow, Text, Pencil, Brush, Eraser
- **Color Controls**: Fill and stroke color pickers
- **Editing**: Transform, scale, rotate, drag & drop
- **History**: Full undo/redo support
- **Themes**: 20+ beautiful DaisyUI themes
- **Export**: PNG, JPG, and PDF export
- **Responsive**: Mobile, tablet, and desktop friendly
- **Image Upload**: Import and edit images

## Installation 🚀

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Tech Stack 💻

- React 19
- Vite
- Konva & React-Konva (Canvas)
- DaisyUI (UI Components)
- Tailwind CSS
- React Icons
- jsPDF (PDF Export)

## Project Structure 📁
```
src/
├── components/     # UI Components
├── constants/      # Action types and constants
├── hooks/          # Custom React hooks
├── utils/          # Helper functions
├── App.jsx         # Main application
└── main.jsx        # Entry point
```

## Usage 📖

1. Select a tool from the sidebar
2. Draw on the canvas
3. Use color pickers to change colors
4. Select objects to edit, transform, or delete
5. Export your design in PNG, JPG, or PDF format
